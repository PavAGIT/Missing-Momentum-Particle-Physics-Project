This code performs a particle physics analysis using simulated collision data from a Muon-Ion Collider (MuIC), with the goal of studying Higgs boson production through the Higgs boson decay to a charm quark–anticharm quark pair. It compares two Higgs signal processes, Charged Current Deep Inelastic Scattering (CCDIS) and Neutral Current Deep Inelastic Scattering (NCDIS), against their corresponding di-charm background processes. The simulated events are generated using MadGraph5_aMC@NLO, Pythia8, and Delphes and stored in ROOT files, which are read and processed using Uproot and other scientific Python libraries.

The analysis extracts relevant kinematic information from each collision event, including missing transverse energy (MET), jet transverse momentum, pseudorapidity, azimuthal angle, mass, and flavor. It also identifies charm-flavored jets using truth-level information and constructs dijet combinations to calculate their combined kinematic properties. Each simulated sample is assigned an event weight based on its theoretical cross-section, target integrated luminosity, and number of generated events to allow for consistent comparisons between processes.

The primary focus of the analysis is comparing the MET distributions of the Higgs signal and di-charm background samples. Histograms are created for each process over a range of 0–125 GeV and normalized to event density. The final output is an overlaid comparison plot showing the MET distributions for the charged-current and neutral-current signal and background processes. This comparison provides an initial investigation into whether missing transverse energy can serve as a useful observable for distinguishing Higgs boson production followed by decay to a charm quark–anticharm quark pair from di-charm background events at a Muon-Ion Collider.
